# ttymagotchi 0.3.0

First release of **ttymagotchi**, a fork of
[Termagotchi v0.2.0 by Eze Olea Figueroa](https://github.com/ezeoleaf/termagotchi).
The upstream history, attribution and MIT license are preserved.

- Five random pet species, ten growth forms, random names and Happiness expressions.
- Animated feeding, sleeping, washing, diaper care, brushing and clear refusal gestures.
- Eight different interactive minigames with score-based rewards.
- Overfeeding, starvation and hygiene neglect affect health; sustained care restores it.
- Discrete diaper accidents, slow brushing needs and configurable simulation speed.
- English, Dutch, French, Spanish and German interfaces.
- Arrow/Enter status shortcuts, Escape navigation and one-percent status bars.
- Automatic import of an existing Termagotchi save without modifying the original.
- Complete PNG art atlas and reproducible review tooling.

Downloads include native **Arch**, **Debian/Ubuntu**, and **Fedora** installers for
Linux x86_64, a portable static executable archive, packaging recipe, source and
SHA-256 checksums. Run `ttymagotchi` after installing; `--version` reports the version.
See the README for commands and care mechanics. The original AUR/Homebrew packages
install upstream Termagotchi, not this fork.
