# Publication preference

For each future change, finish implementation and local verification, then ask the
user whether that change should be published/pushed. Do not push commits or tags,
create releases, or publish packages without their explicit consent for that change.
The initial ttymagotchi fork and its first native package release were explicitly
authorized in the 25 November 2026 session; that authorization is not blanket consent
for later changes. Local edits, tests and commits may proceed within the requested scope.

Preserve attribution to https://github.com/ezeoleaf/termagotchi and its MIT license.
Never commit personal pet saves, credentials, or generated local build directories.
